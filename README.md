# Microplastic Scout – Frontend Interface

## 📌 Overview
Microplastic Scout is a web-based interface designed to visualize and analyze microplastic detection results generated by deep learning models. This frontend application allows users to:
- Upload microscopic images
- Select detection mode (Fast / Accurate)
- Visualize bounding boxes
- View classification results
- Analyze particle counts by type

The system integrates with a Flask-based backend running YOLOv11 and Faster R-CNN models.

## 🧠 System Architecture


User → React Frontend → Flask API → Deep Learning Models → JSON Response → Visualization



The frontend communicates with the backend using REST APIs and renders detection results dynamically.

## ⚙️ Project Setup (Local Development)
### 1️⃣ Clone the Repository
```bash
git clone <YOUR_GIT_URL>
```

### 2️⃣ Navigate to Project Directory

```bash
cd microplastic-scout-main
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Development Server

```bash
npm run dev
```

The application will run locally at: *http://localhost:5173*

## 🔗 Backend Requirement
Ensure that the Flask backend server is running before using the frontend.
Default backend URL: *http://localhost:5000*

## 📊 Features
- Dual detection mode selection:
    - *Fast Mode* → YOLOv11
    - *Accurate Mode* → Faster R-CNN
- Bounding box visualization
- Confidence score display
- Particle type breakdown
- Total microplastic count
- JSON-based API integration
